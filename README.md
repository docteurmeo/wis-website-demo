# Wed in Style - Website Demos

Bản demo thiết kế website cho **Wed in Style** (wedinstyle.vn) - 2 hướng thẩm mỹ để so sánh. Self-contained HTML, mở trực tiếp bằng trình duyệt.

**Landing:** mở `index.html`

## Option 1 - Warm-dark Editorial
Nền mực tối, full-bleed cinema.
- `Homepage.html`
- `Case_CatherineJohnny.html`

## Option 2 - The Walk
Warm daylight, spatial, chuyển động đi ngang. Bản mới nhất.
- `O2_Homepage.html`
- `O2_Case.html`
- `O2_Hero.html`

Menu mỗi option có link chuyển sang option còn lại.

## Ghi chú font
Option 1 dùng MADE Mirage + Beau Sweet Sans (đóng gói trong `assets/fonts/`). Option 2 dùng Google Fonts (Instrument Serif + Pinyon Script). Cả hai hiển thị đúng trên bản live.

`explorations/` là các bản R&D trong quá trình làm.
